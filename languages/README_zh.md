# 图片抓取器
[English](../README.md) | 中文 | [Español](README_es.md) | [Deutsch](README_de.md) | [日本語](README_ja.md) | [Français](README_fr.md)

一款浏览器扩展，自动扫描网页中的图片并支持一键批量下载。

> 基于 Chromium · Manifest V3 · 无追踪 · 侧边栏界面

---

## 功能特性

### 免费功能

| 功能 | 说明 |
|------|------|
| 🔍 **智能图片检测** | 扫描 `<img>`、CSS `background-image`、`<video poster>`、`<source srcset>` 和 SVG `<image>` |
| 🤖 **自动采集** | 页面加载时持续收集图片（MutationObserver + 空闲回调） |
| 📋 **网格与列表视图** | 在缩略图网格和紧凑表格视图之间切换 |
| 🔎 **过滤与排序** | 按最小尺寸和图片类型过滤；按宽度/高度/名称排序 |
| ✅ **批量下载** | 单次批量下载最多 **30 张图片** |
| 🔍 **灯箱预览** | 点击任意图片查看大图，支持键盘导航（← → Esc） |
| ⬇️ **批量下载** | 下载选中图片到 `ImageGrabber/` 文件夹 |
| 💾 **持久化存储** | 图片列表在 Service Worker 重启后保留 |
| 🔄 **SPA 支持** | 检测单页应用导航并自动重新扫描 |

### 高级功能（需要授权）

| 功能 | 说明 |
|------|------|
| ⭐ **无限选择** | 无 30 张限制，随意选择和下载 |
| 🔬 **pHash 去重** | 感知哈希算法识别重复/相似图片，即使 URL 不同也能检测 |
| 🔄 **格式转换** | 下载时转换格式：WebP → JPG、PNG 或其他支持格式 |
| 🗜️ **图片压缩** | 调整质量和最大宽度，减小文件体积 |
| ⭐ **高级下载** | 一键流水线：去重 → 转格式 → 压缩 → 下载 |

## 安装

1. 打开浏览器扩展页面：
   - **Chrome**：`chrome://extensions/`
   - **Edge**：`edge://extensions/`
2. 开启**开发者模式**（右上角开关）
3. 点击**加载已解压的扩展程序**，选择项目文件夹
4. 点击工具栏中的图片抓取器图标打开侧边栏

---

## 使用方法

1. **浏览任意网页** — 内容脚本会在所有页面上自动运行
2. **点击图片抓取器图标**打开侧边栏
3. **开启自动** — 切换"自动"开关，在页面加载时持续收集图片
4. **或点击扫描** — 手动触发一次全页扫描
5. **过滤** — 设置最小宽度/高度，选择图片类型，选择排序方式
6. **切换视图** — 在网格（▦）和列表（☰）布局之间切换
7. **选择** — 点击图片进行选择（免费用户最多 30 张）
8. **预览** — 点击任意图片打开灯箱
9. **下载** — 点击 ⬇️ 基础下载，或 ⭐ 高级下载（需授权）

### 高级下载（需授权）

1. 前往 [VKT 定价页](https://annmax1983.com/pricing.html) 获取授权码
2. 打开设置（⚙️ 齿轮图标）→ 输入授权码
2. 配置输出格式、质量和去重选项
3. 选择图片后点击 ⭐ 高级下载按钮
4. 流水线自动执行：去重（如启用）→ 转格式 → 压缩 → 下载

## 隐私

- 所需权限：`storage`、`downloads`、`sidePanel`
- 所有图片处理均在**浏览器本地运行**，无外部数据上传
- 无分析、无追踪、无数据收集
- 图片数据仅存储在浏览器本地存储中
- 授权验证仅发送设备指纹哈希（基于硬件，不含个人信息）
