# 图片抓取器

[English](../README.md) | 中文 | [Español](README_es.md) | [Deutsch](README_de.md) | [日本語](README_ja.md) | [Français](README_fr.md)

**Image Grabber** 是一款免费的网页图片下载器扩展（Chrome / Edge），自动扫描网页中的图片并支持一键批量下载。

> 基于 Chromium · Manifest V3 · 无追踪 · 侧边栏界面

---

## 功能特性

### 免费功能

| 功能 | 说明 |
|------|------|
| 🔍 **智能图片检测** | 扫描 `<img>`（含 `data-src` / 懒加载属性）、`srcset`（取最大候选）、CSS `background-image`（内联、`::before`、`::after`）、`<video poster>`、`<source srcset>` 和 SVG `<image>` |
| 🤖 **自动采集** | 页面加载时持续收集图片（MutationObserver + 空闲回调） |
| 📋 **网格与列表视图** | 在缩略图网格和紧凑表格视图之间切换 |
| 🔎 **过滤与排序** | 按最小尺寸和图片类型过滤；按宽度、高度或文件名排序 |
| 🎯 **手动拾取** | 直接点击页面上的元素抓取它的图片 |
| 🖼️ **灯箱预览** | 大图预览，支持键盘导航（← → Esc）、下载与复制链接 |
| 🔗 **复制链接** | 把选中的（或当前筛选出的全部）图片 URL 复制到剪贴板 |
| 📥 **批量下载（单次最多 30 张）** | 下载走浏览器自带的下载引擎，Cookie、User-Agent、Referer 全部自动带上——防盗链或需登录的图片也能正常保存 |
| 📊 **下载结果反馈** | 一批下载结束后，用提示条汇报成功与失败的数量 |
| 💾 **状态持久化** | 图片列表和你的「已删除」记录在页面刷新、Service Worker 重启后依然保留 |
| 🔄 **SPA 支持** | 单页应用导航时自动重新扫描（`pushState` / `replaceState` / `popstate`） |

### 高级功能（需要授权）

| 功能 | 说明 |
|------|------|
| ⭐ **无限选择** | 无 30 张限制，随意选择和下载 |
| 🔬 **pHash 去重** | 感知哈希算法识别重复/相似图片，即使 URL 不同也能检测 |
| 🔄 **格式转换** | 下载时转换格式：WebP → JPG、PNG 或其他支持格式 |
| 🗜️ **图片压缩** | 调整质量和最大宽度，减小文件体积 |
| 🚀 **高级下载流水线** | 一键流水线：去重 → 转格式 → 压缩 → 下载 |

### 2.0.7 更新内容

- **名称与简介改为搜索词导向** —— 扩展名里加入了高频搜索词「图片下载器 / Image Downloader」，简介把关键词提到最前（6 种语言同步）。
- **文档与官网 SEO 补全** —— README 首句重写、官网产品页描述与社交分享卡片补齐。

### 2.0.6 更新内容

- **防盗链图片现在真的能存下来** —— 面板发起的图片请求会通过会话级 `declarativeNetRequest` 规则带上页面的 `Referer`，但浏览器自带的下载引擎不会带，所以在防盗链站点上「下载成功」的背后，存到磁盘的可能只是一个 403 错误页。现在改为在扩展面板内取回图片（带上页面 Cookie 与 `Referer`），再以 blob 交给下载引擎，防盗链与仅登录可见的图片都能存成原图。
- **真实统计成功/失败数量** —— 完成提示条会等每一张真正下载结束再汇报，不再把「已发起」当成「已完成」。
- **高级下载在防盗链站点可用** —— 去重 → 转格式 → 压缩流水线以前无法把防盗链图片读进 canvas。现在每张图都走同一套带凭证的取图流程，pHash 去重与格式转换恢复正常；无法重新编码的文件会回退成下载原图，而不是被丢弃。

## 安装

1. 打开浏览器扩展页面：
   - **Chrome**：`chrome://extensions/`
   - **Edge**：`edge://extensions/`
2. 开启**开发者模式**（右上角开关）
3. 点击**加载已解压的扩展程序**，选择项目文件夹
4. 点击工具栏中的图片抓取器图标打开侧边栏

---

## 使用方法

1. **浏览任意网页** —— 内容脚本会采集当前页面的图片
2. **点击图片抓取器图标**打开侧边栏
3. **开启自动** —— 切换「自动」开关，在页面加载时持续收集图片
4. **或点击扫描** —— 手动触发一次全页扫描
5. **过滤** —— 设置最小宽度/高度，选择图片类型，选择排序方式
6. **切换视图** —— 在网格（▦）和列表（☰）布局之间切换
7. **选择** —— 点击图片进行选择（免费用户最多 30 张）
8. **预览** —— 点击任意图片打开灯箱
9. **复制** —— 用复制按钮把选中图片的链接放到剪贴板
10. **下载** —— 点击 ⬇️ 基础下载，或 ⭐ 高级下载（需授权）。完成后提示条会汇报成功与失败的数量

### 高级下载（需授权）

1. 前往 [annmax1983.com](https://www.annmax1983.com/checkout.html?plugin=imagegrabber) 获取授权码
2. 打开设置（⚙️ 齿轮图标）→ 输入授权码
3. 配置输出格式、质量和去重选项
4. 选择图片后点击 ⭐ 高级下载按钮
5. 流水线自动执行：去重（如启用）→ 转格式 → 压缩 → 下载

## 隐私

- 所需权限：`storage`、`downloads`、`sidePanel`、`declarativeNetRequest`
- 需要 `<all_urls>` 主机权限，才能检测并下载任意域名下的图片
- `declarativeNetRequest` 仅用于设置 `Referer` 请求头。面板展示某个标签页的图片期间规则保持生效（让防盗链站点的缩略图也能显示），下载批次期间同样生效（让保存下来的文件是真正的原图而非错误占位图）。规则只作用于当前屏幕上出现的图片域名，并在关闭面板、切换标签页或页面跳转时移除
- 所有图片处理均在**浏览器本地运行**，无外部数据上传
- 无分析、无追踪、无数据收集
- 图片数据仅存储在浏览器本地存储中
- 授权验证发送许可证密钥、随机安装标识和基础浏览器信息 —— 绝不包含图片、页面内容或浏览数据
