# Image Grabber

[English](../README.md) | [中文](README_zh.md) | [Español](README_es.md) | [Deutsch](README_de.md) | 日本語 | [Français](README_fr.md)

**Image Grabber** は Chrome / Edge 向けの無料画像ダウンローダー拡張機能です。Web ページをスキャンし、ワンクリックで画像を一括ダウンロードできます。

> Chrome / Edge / Firefox · Manifest V3 · トラッキングなし · サイドパネル / ポップアップUI

---

## 機能一覧

### 無料機能

| 機能 | 説明 |
|---------|-------------|
| 🔍 **スマート画像検出** | `<img>`（`data-src` / 遅延読み込み属性を含む）、`srcset`（最大の候補を採用）、CSS `background-image`（インライン、`::before`、`::after`）、`<video poster>`、`<source srcset>`、SVG `<image>`をスキャン |
| 💎 **原画像検出** | ページ上に公開されている高解像度の原画像（遅延読み込みの`data-*`属性、親の画像リンク、`<picture>` / `srcset`の候補）を検出し、実際の寸法を確認してから採用します。より大きい原画像が確認できない場合は表示中の画像を使用します。**Original**スイッチで無効化できます |
| 🤖 **自動収集** | ページ読み込み中に画像を継続的に収集（MutationObserver＋idle callback） |
| 📋 **グリッド＆リスト表示** | サムネイルグリッドとコンパクトテーブル表示を切り替え |
| 🔎 **フィルター＆ソート** | 最小寸法と画像タイプでフィルタリング、幅・高さ・ファイル名でソート |
| 🎯 **手動ピック** | ページ上の要素を直接クリックしてその画像を取得 |
| 🖼️ **ライトボックスプレビュー** | キーボードナビゲーション対応のフルサイズプレビュー（← → Esc）、ダウンロードとURLコピー |
| 🔗 **URLをコピー** | 選択した画像（または現在のフィルター結果すべて）のURLをクリップボードにコピー |
| 📥 **バッチダウンロード（1回最大30枚）** | 各画像を拡張機能ページ内でページのCookieと`Referer`付きで取得し、blobとしてダウンロードエンジンに渡します — 直リンク保護やログイン必須の画像も403ページではなく実ファイルとして保存されます。バッチ完了までパネルを開いたままにしてください |
| 📊 **ダウンロード結果レポート** | バッチ終了時に、成功した件数と失敗した件数をトーストで通知 |
| 💾 **状態永続化** | 画像リストと「削除済み」マークがページ再読み込みやService Worker再起動後も保持されます |
| 🔄 **SPA対応** | 実際のナビゲーションと`pushState` / `replaceState` / `popstate`を検出し、前のページの画像を消去して新しい画面を自動再スキャンします |

### Premium機能（ライセンス必要）

| 機能 | 説明 |
|---------|-------------|
| ⭐ **無制限の選択** | 30枚制限なし — 任意の数を選択・ダウンロード |
| 🔬 **pHash重複排除** | 知覚ハッシュで異なるURLの重複・類似画像を検出 |
| 🔄 **フォーマット変換** | ダウンロード時にJPG・PNG・WebPへ変換。GIF・SVG・AVIFなどの元フォーマットは非可逆な再エンコードをせずそのまま保持します |
| 🗜️ **画像圧縮** | 品質と最大幅を調整してファイルサイズを削減。**Original**でリサイズなしの場合、元のバイト列をそのままダウンロードします |
| 🚀 **高度なダウンロードパイプライン** | ワンクリックパイプライン：重複排除 → 変換/リサイズ（要求時のみ）→ ダウンロード |

## 対応ブラウザ

| ブラウザ | ステータス |
|---------|--------|
| Google Chrome | ✅ 完全対応（サイドパネル） |
| Microsoft Edge | ✅ 完全対応（サイドパネル） |
| Mozilla Firefox | ✅ 完全対応 |
| その他のChromium系ブラウザ | ✅ 対応（ポップアップフォールバック） |

> **Firefox について：** Firefox には `sidePanel` API がないため、拡張機能は**ツールバーのポップアップ**として開きます。ポップアップには一覧/グリッド表示、フィルター、選択、ダウンロード、ライセンスキー入力という作業用の全機能が含まれ、まとめてダウンロードする場合は独立タブも利用できます。唯一の例外は **🎯 Manual Pick** で、これは Chrome / Edge のサイドパネル機能のため Firefox 版では提供されません。Firefox 版は `sidePanel` 権限を要求しません。まとめてダウンロードする間はポップアップまたはタブを開いたままにしてください（ダウンロードはそのページから実行されます）。

## 使い方

1. **任意のWebページを閲覧** — コンテンツスクリプトが現在のページから画像を収集します
2. **Image Grabberアイコンをクリック**してサイドパネルを開きます
3. **自動を有効化** — 「自動」トグルでページ読み込み中に画像を継続的に収集します
4. **またはスキャンをクリック** — 手動でページ全体のスキャンを実行します
5. **フィルター** — 最小幅/高さを設定し、画像タイプと並び順を選択します
6. **表示切替** — グリッド（▦）とリスト（☰）レイアウトを切り替えます
7. **選択** — 画像をクリックして選択（無料ユーザーは最大30枚）
8. **プレビュー** — 任意の画像をクリックしてライトボックスを開きます
9. **コピー** — コピーボタンで選択した画像のURLをクリップボードに入れます
10. **ダウンロード** — ⬇️で基本ダウンロード、⭐で高度なダウンロード（Premium）。完了後、ダウンロードできた件数と失敗した件数がトーストで通知されます。ダウンロードはパネルページが実行するため、バッチ完了まで開いたままにしてください

### 高度なダウンロード（Premium）

1. [annmax1983.com](https://www.annmax1983.com/checkout.html?plugin=imagegrabber)からライセンスキーを取得します
2. 設定（⚙️歯車アイコン）を開き、ライセンスキーを入力します
3. 出力フォーマット、品質、重複排除オプションを設定します
4. 画像を選択し、⭐高度なダウンロードボタンをクリックします
5. パイプラインが実行されます：重複排除（有効な場合）→ 変換/リサイズ（フォーマットまたは最大幅を指定した場合のみ）→ ダウンロード

変換先はJPG・PNG・WebPに限定されます。GIF・SVG・AVIF・BMPなどは元のフォーマットでダウンロードされます（変換を要求した場合はダウングレードとして報告）。**Original**で最大幅なしの場合、品質スライダーに関係なく元のバイト列を再エンコードせずにダウンロードします。

## プライバシー

- 必要な権限：`storage`、`downloads`、`sidePanel`、`declarativeNetRequest` （`sidePanel` は Chrome / Edge のみ。Firefox はこの権限を要求せず、ツールバーのポップアップで動作します）
- 任意のドメインの画像を検出・ダウンロードするために、ホスト権限`<all_urls>`が必要です
- `declarativeNetRequest`は`Referer`ヘッダーの設定にのみ使用されます。パネルがタブの画像を表示している間（直リンク保護されたサイトでもプレビューが読み込めるように）、およびダウンロードバッチの間（保存されるファイルがエラーのプレースホルダーではなく本来の実画像になるように）ルールが有効です。ルールは画面に表示されている画像のドメインに限定され、パネルを閉じる・タブを切り替える・ページが遷移した時点で削除されます
- ルールが有効な間は、拡張機能自身の画像取得だけでなく、それらの画像ドメインへのリクエスト全般に適用されます。バッチ中にページから同じ画像ドメインへ送られるリクエストにもページの`Referer`が付きます。ルールはセッション単位・ドメイン単位で、ヘッダーを永続的に書き換えるものではありません
- SPAナビゲーションは`location.href`の比較によりローカルで検出します。閲覧履歴の読み取り・記録・送信は行いません
- 原画像検出は候補URLを一時的な画像読み込みでローカルに検査します。このリクエストは画像のホスト（ページの画像を配信しているのと同じホスト）へ直接送信されます。読み取るのは寸法のみで、画像内容のアップロードや保存は行わず、確認済みの結果はローカルストレージにのみ保存されます。**Original**スイッチで無効化できます
- すべての画像処理はブラウザ内で**ローカル**に実行されます — 外部データアップロードなし
- アナリティクス、ユーザートラッキング、リモートデータ収集はありません
- 画像データはブラウザのローカルストレージにのみ保存されます
- ライセンス検証で送信されるのはライセンスキー、ランダムなインストール識別子、基本的なブラウザーメタデータのみです（画像・ページ内容・閲覧履歴は送信されません）
